Features

Everything brew does, without the terminal.

CaskHub runs everything through your real brew binary, so anything you install here can be managed from the command line, and vice versa.

Browse thousands of Mac apps

Curated shelves, a rotating hero pick, a Featured top 100, and every cask classified into browsable categories.

Top Charts, real install data

The most-installed casks ranked by Homebrew's public analytics, with 30, 90, and 365-day windows.

Recently added

New arrivals to Homebrew from the last 30-90 days, so you catch new apps early.

One-click everything

Install, update, and uninstall with live progress states and cancellable downloads. pkg installers get a native macOS password prompt.

Adopt existing apps

Installed something from a DMG or another store? Bring it under brew management with one click. The app stays right where it is.

Updates that matter

Smart detection skips self-updating apps and normalizes packaging quirks, so the Updates badge only shows real updates.

Instant search

Search across names, tokens, and descriptions with ⌘F. Original app icons and rich metadata make results easy to scan.

Fully compatible with the CLI

CaskHub reads your real Caskroom and shells out to your real brew. It even detects apps you installed from the terminal.

Native & polished

Grid and list views, flexible sorting, light and dark themes, and bundled category data, so browsing never blocks on the network.

How it works

Three levels of Homebrew, one app.

Catalog & analytics

The catalog and install charts come from the public Homebrew API. No Homebrew installation is required just to browse.

Installed-app detection

CaskHub reads install receipts directly from your Caskroom. Fast, offline, and no shelling out needed.

Real brew actions

Installs, updates, and uninstalls run through your actual brew binary, staying fully compatible with the command line.

Make yourself at home

Comes in light and dark.

Standard or Classic. Pick the look that feels like your Mac.

Showing both designs in dark mode.

Private by default

Anonymous usage metrics, with TelemetryDeck limited to anonymous session and new-install reporting. You can opt out of everything in Settings → Privacy.

Free & open source

MIT licensed, built in the open with SwiftUI. No subscription, no premium tier, no ads. Read the source or build it yourself.

FAQ

Last call questions.

Do I need Homebrew?

Only to install apps. Browsing works without it, and CaskHub walks you through the setup if it's missing.

What does it cost?

Nothing, ever. Free and MIT-licensed. No ads, no tiers, no subscriptions.

Which macOS?

macOS 15.6 or later, on both Apple Silicon and Intel.
